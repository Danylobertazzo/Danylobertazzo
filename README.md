## What I'm building

**[envio-guias](https://github.com/Danylobertazzo/envio-guias)**: automated delivery of tax documents for an accounting firm.
- Reads the company ID (CNPJ) inside each PDF and matches it to the right client.
- The first version, in Python, is used every month: in November 2026 it sent 73 payment slips in one batch.
- Now rebuilding it as a multi-user web system in **C# / .NET 10**: ASP.NET Core, Entity Framework Core, SQLite, xUnit (82 tests).
- Real client data never goes to the repository; tests use fictitious companies.
